# Security policy

## Reporting a vulnerability

Email **support@tintloom.com** with "Security" in the subject. Please do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, and the plugin version (`plugins/tintloom/.claude-plugin/plugin.json`). We reply within 3 working days, keep you updated while we fix it, and credit you in the release notes if you want that.

This policy covers this plugin and the hosted Tintloom connector at https://mcp.tintloom.com. Please test only against your own accounts and keys, and do not read or change other people's data.

## Supported versions

The latest release of the plugin gets fixes. Update with `claude plugin update tintloom@tintloom`.
